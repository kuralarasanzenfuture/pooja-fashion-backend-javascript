# Taxes Postman Collection

This directory contains testing resources for the **Taxes** module (`032_taxes.sql`).

## Files
- `taxes-api-docs.md`: Complete API reference manual including seeding and POS calculation examples.
- `taxes.postman_collection.json`: Postman v2.1 importable collection covering all endpoints.

## How to Import
1. Open **Postman**.
2. Click **Import** in the top left.
3. Select `taxes.postman_collection.json`.
4. Ensure `base_url` points to your backend server (e.g. `http://localhost:5000`).
