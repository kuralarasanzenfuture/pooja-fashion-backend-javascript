# Product Taxes Postman Collection

This directory contains testing resources for the **Product Taxes** module (`033_product_taxes.sql`).

## Files
- `product-taxes-api-docs.md`: Comprehensive API reference manual with POS resolution hierarchy rules.
- `product-taxes.postman_collection.json`: Postman v2.1 collection.

## How to Import
1. Open **Postman**.
2. Click **Import** in the top left.
3. Select `product-taxes.postman_collection.json`.
4. Ensure `base_url` points to your backend server (e.g. `http://localhost:5000`).
