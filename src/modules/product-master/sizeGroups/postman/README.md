# Postman Collection - Product Master: Size Groups

This folder contains the complete Postman collection and documentation for the **Size Groups** module under Product Master.

## Files
- `size-groups.postman_collection.json`: Importable Postman v2.1 collection.
- `size-groups-api-docs.md`: Comprehensive API reference with request and response payloads.

## Getting Started
1. Open Postman.
2. Click **Import** and select `size-groups.postman_collection.json`.
3. Set your collection variables:
   - `baseUrl`: e.g. `http://localhost:5000`
   - `companyId`: e.g. `1`
   - `sizeGroupId`: e.g. `1`
   - `sizeGroupCode`: e.g. `MEN`
4. Run requests to test size group creation, listing, updating, default seeding, status toggling, and deletion.
