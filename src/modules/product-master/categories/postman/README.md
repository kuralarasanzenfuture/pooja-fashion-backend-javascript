# Postman Collection - Product Master: Categories

This folder contains the complete Postman collection and documentation for the **Categories** module under Product Master.

## Files
- `categories.postman_collection.json`: Importable Postman v2.1 collection.
- `categories-api-docs.md`: Comprehensive API reference with request and response payloads.

## Getting Started
1. Open Postman.
2. Click **Import** and select `categories.postman_collection.json`.
3. Set your collection variables:
   - `baseUrl`: e.g. `http://localhost:5000`
   - `companyId`: e.g. `1`
   - `categoryId`: e.g. `1`
   - `categoryCode`: e.g. `WOMENS_ETHNIC`
4. Run requests to test category creation, listing, updating, image management, status toggling, and deletion.
