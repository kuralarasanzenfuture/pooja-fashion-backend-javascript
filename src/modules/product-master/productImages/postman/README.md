# Product Images Postman Collection & Documentation

This directory contains the Postman collection and API documentation for **Product Images** under **Product Master** in the Pooja Fashion ERP & POS platform.

## Files
- `product-images.postman_collection.json`: Importable Postman Collection (v2.1) with pre-configured requests for image upload, metadata editing, reordering, and deletion.
- `product-images-api-docs.md`: Comprehensive API reference guide.

## Quick Start
1. Open Postman.
2. Click **Import** and select `product-images.postman_collection.json`.
3. Set your environment variables:
   - `baseUrl`: e.g. `http://localhost:5000`
   - `companyId`: e.g. `1`
   - `productId`: e.g. `1`
   - `imageId`: e.g. `1`
4. Test and execute requests!
