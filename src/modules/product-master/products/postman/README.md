# Products Postman Collection & Documentation

This folder contains Postman assets and API documentation for the **Products** module under **Product Master** in the Pooja Fashion ERP & POS platform.

## Files
- `products.postman_collection.json`: Importable Postman Collection (v2.1) with pre-configured requests and query parameters.
- `products-api-docs.md`: Comprehensive API reference guide with request/response schemas.

## Quick Start
1. Open Postman.
2. Click **Import** and select `products.postman_collection.json`.
3. Set your environment variables:
   - `baseUrl`: e.g. `http://localhost:5000`
   - `companyId`: e.g. `1`
   - `productId`: e.g. `1`
   - `productCode`: e.g. `SILK_ANARKALI_01`
4. Test and execute requests!
