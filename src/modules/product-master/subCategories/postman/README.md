# Postman Collection - Product Master: Subcategories

This folder contains the complete Postman collection and documentation for the **Subcategories** module under Product Master.

## Files
- `subcategories.postman_collection.json`: Importable Postman v2.1 collection.
- `subcategories-api-docs.md`: Comprehensive API reference with request and response payloads.

## Getting Started
1. Open Postman.
2. Click **Import** and select `subcategories.postman_collection.json`.
3. Set your collection variables:
   - `baseUrl`: e.g. `http://localhost:5000`
   - `companyId`: e.g. `1`
   - `categoryId`: e.g. `1`
   - `subcategoryId`: e.g. `1`
   - `subcategoryCode`: e.g. `SILK_SAREES`
4. Run requests to test subcategory creation, listing, updating, category-filtering, image management, status toggling, and deletion.
