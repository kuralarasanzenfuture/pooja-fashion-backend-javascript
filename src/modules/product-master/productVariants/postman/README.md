# Product Variants Postman Collection & Documentation

This directory contains the Postman collection and API documentation for **Product Variants** under **Product Master** in the Pooja Fashion ERP & POS platform.

## Files
- `product-variants.postman_collection.json`: Importable Postman Collection (v2.1) with pre-configured requests and query parameters.
- `product-variants-api-docs.md`: Complete API specification including request bodies and response schemas.

## Quick Start
1. Open Postman.
2. Click **Import** and select `product-variants.postman_collection.json`.
3. Set your environment variables:
   - `baseUrl`: e.g. `http://localhost:5000`
   - `companyId`: e.g. `1`
   - `productId`: e.g. `1`
   - `variantId`: e.g. `1`
   - `sku`: e.g. `SILK-ANK-M-RED`
4. Test and execute requests!
