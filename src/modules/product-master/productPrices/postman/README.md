# Product Prices & Price History Postman Collection

This directory contains testing resources for the **Product Prices** and **Product Price History** modules.

## Files
- `product-prices-api-docs.md`: Comprehensive API reference manual with request/response payloads, constraints, and audit trail mechanics.
- `product-prices.postman_collection.json`: Postman v2.1 importable collection covering all endpoints.

## How to Import
1. Open **Postman**.
2. Click **Import** in the top left.
3. Drag and drop `product-prices.postman_collection.json`.
4. Verify the `base_url` variable is set to your active backend server (default: `http://localhost:5000`).
