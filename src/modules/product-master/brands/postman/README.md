# Postman Collection - Product Master: Brands

This folder contains the complete Postman collection and documentation for the **Brands** module under Product Master.

## Files
- `brands.postman_collection.json`: Importable Postman v2.1 collection.
- `brands-api-docs.md`: Comprehensive API reference with request and response payloads.

## Getting Started
1. Open Postman.
2. Click **Import** and select `brands.postman_collection.json`.
3. Set your collection variables:
   - `baseUrl`: e.g. `http://localhost:5000`
   - `companyId`: e.g. `1`
   - `brandId`: e.g. `1`
   - `brandCode`: e.g. `POOJA_EXCLUSIVE`
4. Run requests to test brand creation, listing, updating, logo uploads, status toggling, and deletion.
