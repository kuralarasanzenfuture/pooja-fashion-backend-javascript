# Discounts Postman Collection

This directory contains testing resources for the **Discounts** module (`034_discounts.sql`).

## Files
- `discounts-api-docs.md`: Comprehensive API reference manual with POS discount calculation examples.
- `discounts.postman_collection.json`: Postman v2.1 importable collection covering all endpoints.

## How to Import
1. Open **Postman**.
2. Click **Import** in the top left.
3. Select `discounts.postman_collection.json`.
4. Ensure `base_url` points to your backend server (e.g. `http://localhost:5000`).
