# Product Barcodes Postman Collection & Documentation

This folder contains Postman collections and API documentation for **Product Barcodes** and POS Scanning under **Product Master** in the Pooja Fashion ERP & POS platform.

## Files
- `product-barcodes.postman_collection.json`: Importable Postman Collection (v2.1) with pre-configured requests for CRUD and POS barcode scan lookup.
- `product-barcodes-api-docs.md`: Comprehensive API reference guide.

## Quick Start
1. Open Postman.
2. Click **Import** and choose `product-barcodes.postman_collection.json`.
3. Set your environment variables:
   - `baseUrl`: e.g. `http://localhost:5000`
   - `companyId`: e.g. `1`
   - `barcodeId`: e.g. `1`
   - `barcode`: e.g. `8901234567890`
4. Test and execute requests!
